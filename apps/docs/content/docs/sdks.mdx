## What exists today

| | Status |
|---|---|
| **Go** | No module to fetch yet. The [Go guide](/docs/guides/go) has a copy-in client (standard library only) that sends, schedules, reads status, cancels and verifies webhooks |
| **TypeScript** client | One file, `clients/typescript/index.ts`: copy it into your project. It sends, cancels, reads status and verifies webhooks. **It is not published to npm** |
| **Python** | No package. Plain HTTP with `requests`: the [Python guide](/docs/guides/python) has a copy-in client, OTP, password reset and webhook verification |
| **PHP / Laravel** | No package. Laravel's `Http` client or cURL: the [PHP and Laravel guide](/docs/guides/php-laravel) |
| **Java / Spring Boot** | No Maven artifact. `java.net.http` plus Jackson: the [Java guide](/docs/guides/java) has a copy-in client and a Spring Boot webhook controller |
| Any other language | Call the HTTP API using the [OpenAPI file](/openapi.yaml); the [quickstart](/docs/quickstart) shows curl |

Packages published to npm, PyPI, Packagist, Maven Central or a Go proxy are [planned](/docs/roadmap), not available. Do not run `npm install`, `pip install`, `composer require` or `go get`, or add a Maven dependency, for a Njiwa-Mail package.

## Go

The Go client in the repository (`client/`) is not published under a fetchable module path yet, so `go get` does not work. Copy the client from the [Go guide](/docs/guides/go) into your module instead.

## Agent skill [#agent-skill]

Coding agents get the same facts from three machine-readable routes, all generated from this documentation at the same version:

- [`/llms.txt`](/llms.txt): an index of every page.
- [`/llms-full.txt`](/llms-full.txt): every page in one file.
- Every page as Markdown: add `.md` to its URL, for example `/docs/quickstart.md`.
- [`/openapi.yaml`](/openapi.yaml) and [`/openapi.json`](/openapi.json): the API contract.
- [`/skills/njiwa-mail-integration/SKILL.md`](/skills/njiwa-mail-integration/SKILL.md): a short skill with playbooks for OTP, password reset, webhooks, key management, DNS diagnostics, and both mail transports. It names only endpoints that exist, and a test fails if it does not.

<Callout title="For agents">
Fetch `/llms.txt`, then the page you need as `.md`, then `/openapi.yaml`. Use only what they document. If something is missing, say so instead of guessing an endpoint or a package name.
</Callout>
