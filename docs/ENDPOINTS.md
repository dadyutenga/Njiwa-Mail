## Tables

`(sealed)` columns hold AES-GCM ciphertext (see `njiwa-mail rekey`); `*_hash` columns are keyed HMACs or SHA-256 digests.

- **`alert_channels`**: Where operator alerts are sent (webhook or email), per alert kind.  
  Columns: id, kind, target, enabled, created_at
- **`alerts`**: Operator alerts (policy bounces, disabled webhooks, failing checks) with acknowledgement.  
  Columns: id, kind, summary, details, created_at, acknowledged_at, acknowledged_by
- **`api_keys`**: API keys per project environment: prefix, secret hash, scopes, IP allowlist, expiry, revocation.  
  Columns: id, prefix, secret_hash, project_id, environment_id, scopes, label, created_at, expires_at, revoked_at, last_used_at, ip_allowlist, rate_per_minute
- **`audit_log`**: Append-only record of every change made by a person, an API key or the CLI.  
  Columns: id, at, user_id, api_key_id, actor, action, target_type, target_id, details
- **`automation_rules`**: Rules that act on inbound mail (auto-reply, forward, webhook, archive), ordered.  
  Columns: id, project_id, environment_id, address_id, position, name, enabled, cond_sender, cond_subject, cond_has_attachment, action, target, template_id, created_at
- **`automation_runs`**: One row per rule evaluation, with the outcome.  
  Columns: id, rule_id, inbound_id, result, detail, dry_run, message_id, at
- **`autoreply_log`**: Limits auto-replies to one per sender per day.  
  Columns: rule_id, sender_hash, day
- **`blocked_senders`**: Inbound senders an operator blocked in an environment.  
  Columns: environment_id, sender, created_at
- **`bounces`**: Bounce and complaint reports, correlated to a message by signed return path or header.  
  Columns: id, message_id, project_id, environment_id, recipient_hash, recipient_masked, type, status_code, diagnostic, dedupe_hash, received_at, correlated_by
- **`bulk_unsubscribes`**: Recipients who unsubscribed from bulk announcements.  
  Columns: environment_id, recipient_hash, recipient_masked, campaign_id, created_at
- **`campaign_recipients`**: Recipients of a bulk announcement (address sealed, keyed hash for lookups).  
  Columns: id, campaign_id, recipient_hash, recipient_masked, email_enc (sealed), vars_enc (sealed), state, skip_reason, message_id
- **`campaigns`**: Bulk announcements: template, schedule, state, health counters.  
  Columns: id, project_id, environment_id, name, sender_email, subject, html, text_body, template_id, locale, state, pause_reason, send_at, rate_per_minute, created_by, created_at, started_at, completed_at
- **`delivery_events`**: Delivery evidence per message: SMTP reply, mail server log, bounce report, operator note.  
  Columns: id, message_id, source, event, smtp_status, remote_host, safe_reason, mta_queue_id, dedupe_key, observed_at, created_at
- **`dns_changes`**: Append-only ledger of DNS record changes: previous and new value, actor, outcome (used for rollback).  
  Columns: id, setup_id, project_id, domain, zone_id, item_key, action, record_id, record_type, record_name, previous, new, adopted, status, actor, error_code, note, applied_at, rolled_back_at
- **`dns_checks`**: History of DNS check results per record.  
  Columns: id, domain, record_type, expected, observed, pass, checked_at
- **`dns_connections`**: A project's connection to a DNS host (Cloudflare): sealed credential, status, expiry. Never returned by any API.  
  Columns: id, project_id, provider, auth_method, label, token_enc (sealed), refresh_enc (sealed), expires_at, status, status_detail, zone_count, created_by, created_at, last_verified_at, rotated_at, disconnected_at
- **`dns_oauth_states`**: Single-use, hashed OAuth state with a sealed PKCE verifier, bound to the user who started the flow.  
  Columns: state_hash, project_id, user_id, verifier_enc (sealed), redirect_uri, domain_id, created_at, expires_at, used_at
- **`dns_setups`**: One DNS setup run for a domain: zone, reviewed plan and digest, approval, status.  
  Columns: id, project_id, domain_id, domain, connection_id, zone_id, zone_name, status, plan, plan_digest, approved_by, approved_at, acknowledged, applied_at, created_by, created_at, updated_at
- **`domain_claims`**: Installation-wide ownership of a sending domain: one project holds a name.  
  Columns: name, project_id, state, claimed_at, updated_at
- **`domains`**: Sending and receiving domains of a project with DNS check results, DKIM proof and return-path domain.  
  Columns: id, project_id, name, purpose, verify_token, verified_at, spf_ok, dkim_ok, dmarc_ok, created_at, mx_ok, bulk, records, last_checked_at, mailcow_provisioned_at, dkim_verified_at, dkim_verified_selector, dkim_verified_source, bounce_domain
- **`drafts`**: Compose drafts (content sealed).  
  Columns: id, project_id, environment_id, user_id, data_enc (sealed), subject, created_at, updated_at
- **`environments`**: Sandbox and Live environment of a project: enabled flag, approved origins, recipient allowlist.  
  Columns: id, project_id, mode, approved_origins, restrict_recipients, recipient_allowlist, enabled
- **`inbound_addresses`**: Addresses that receive mail into a project (mailboxes, temporary inboxes, catch-all).  
  Columns: id, project_id, environment_id, domain, local_part, enabled, webhook_endpoint_id, created_at, route, forward_to, display_name, temporary, expires_at
- **`inbound_attachments`**: Metadata of inbound attachments; the files are sealed on disk.  
  Columns: id, inbound_message_id, filename, content_type, size, storage_path, sha256, encrypted
- **`inbound_messages`**: Parsed inbound mail (text and HTML sealed) with retention timestamps.  
  Columns: id, project_id, environment_id, address_id, spool_id, envelope_from, envelope_to, header_from, subject, text_enc (sealed), html_enc (sealed), headers, spam_score, raw_size, received_at, retention_expires_at, bodies_purged_at, in_reply_to_message_id, search_tsv, read_at, archived_at, labels
- **`inbound_spool`**: Raw inbound mail accepted by the listener, waiting to be parsed or correlated as bounces.  
  Columns: id, kind, envelope_from, envelope_to, path, size, state, attempts, lease_expires_at, error_code, received_at
- **`installation_checks`**: Connection and readiness check results bound to a transport profile revision.
